# ToneRelay for Android 1.0.0

Official release for Android 10 or later. In-app purchasing is now available at USD 6.99 once per Android phone; taxes are shown at Creem checkout. After purchase, enter the activation code from your receipt email in the app. Each code permanently binds to one phone. Windows licenses are separate.

The free trial lasts 168 continuous hours from the first successful transmission of valid audio. Initial trial registration requires internet; restarting does not require an online time check. Activated licenses work offline. A refund may be requested within 14 days, without affecting statutory consumer rights.

Playback profiles remain Stable 250 ms, Low latency 150 ms (default), and Fast 100 ms. Existing descriptions, automatic reconnect, volume controls and audio behavior are retained. Buffer targets are not measured end-to-end latency.

Install over the previous official APK to retain data. Do not uninstall first. This package uses the existing official signing certificate. Website and GitHub provide identical APK bytes; source code and signing keys remain private.
