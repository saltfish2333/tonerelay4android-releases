This preview adds quick casting, notification/Quick Settings controls, and automatic reconnect. Three playback profiles are available; Low latency is the default.

ToneRelay for Android requires Android 10 or later and a compatible speaker on the same Wi-Fi network. Audio capture depends on the source app allowing Android playback capture.

User testing confirms playback with HomePod, Apple TV and AirPlay-capable Sonos devices. Other compatible AirPlay receivers may also work; support depends on the receiver model, source app and network. This does not include Sonos models without AirPlay support.

## Planned license

The trial lasts 168 continuous hours from the first successful transmission of valid audio. The first trial registration requires internet access. Restarting the phone does not require an online time check.

The planned price is USD 9.99 once per Android device, with taxes shown at checkout. Permanent activation supports offline use after activation. A code cannot be transferred to another device. ## Install and update

Download the `.apk` asset on the phone and allow installation from the browser or file manager you used. For an update, install the newer APK over the previous official version to retain application data. Do not uninstall first.

Development and sandbox builds use a different signing certificate and cannot be updated directly to the public release. Contact support before replacing a test installation.

Do not upload activation codes, device identifiers or payment information to public issues.
