Official release repository for ToneRelay for Android. This repository contains APK downloads, version notes and SHA-256 checksums only. Application source code and signing keys are not published here.

## Release status

The Android release is being prepared. Public APK downloads and paid activation are not open yet. Do not purchase a Windows license for the Android app.

Website downloads and GitHub releases will provide the same signed APK. Each release will include its version, minimum Android version, APK SHA-256 and signing certificate fingerprint.

ToneRelay for Android requires Android 10 or later and a compatible speaker on the same Wi-Fi network. Audio capture depends on the source app allowing Android playback capture.

## Planned license

The trial lasts 168 continuous hours from the first successful transmission of valid audio. The first trial registration requires internet access. Restarting the phone does not require an online time check.

The planned price is USD 9.99 once per Android device, with taxes shown at checkout. Permanent activation supports offline use after activation. A code cannot be transferred to another device. The final purchase and refund information will be provided on the website before paid sales open.

## Install and update

When a release becomes available, download its `.apk` asset on the phone and allow installation from the browser or file manager you used. For an update, install the newer APK over the previous official version to retain application data. Do not uninstall first.

Development and sandbox builds use a different signing certificate and cannot be updated directly to the public release. Contact support before replacing a test installation.

Do not upload activation codes, device identifiers or payment information to public issues.
